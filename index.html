Eintrag 1: Der Bus-Faktor

Definition: Der Bus-Faktor beschreibt das Risiko von Wissens- oder Datenverlust in einem Projekt.

Ganz einfach ausgedrückt: "Wie viele Personen aus meinem Projekt müssen von einem Bus überfahren werden (oder im Lotto gewinnen), damit das gesamte Projekt plötzlich stillsteht?"

  • Bus-Faktor = 1: Absolut kritisch. Nur eine einzige Person hat den Zugriff. Fällt sie aus, brennt die Hütte.

Eintrag 2: Mein erster Security-Fix (22.05.2026)

Was heute passiert ist: Mein persönliches Cockpit-Dashboard war ohne Passwort für jeden im Internet lesbar. Außerdem lag der Code ungesichert auf der Festplatte (Bus-Faktor von praktisch 0).

Die Lösung: Gemeinsam mit Q haben wir den Code in Git gerettet und ich habe manuell im Cloudflare Zero Trust Dashboard ein digitales Schloss (Access-Schranke) vorgeschaltet. Jetzt sind die Daten sicher vor neugierigen Blicken!
