🚀 Meine IT-Roadmap: Die Basics

Das Fundament, das ich verstehen will, um mein Cockpit-Projekt zu meistern.

Säule 1: Das Gesicht

Frontend (HTML & CSS)

Alles, was man im Browser sehen, anklicken und anfassen kann. Das visuelle Erlebnis.

  • HTML (Das Skelett): Definiert die Struktur (Texte, Überschriften, Boxen).
  • CSS (Das Design): Macht die Seite hübsch (Farben, Layouts, Animationen, Dark Mode).
  • Dein Status: Du hast heute bereits CSS-Animationen live geschaltet!
Säule 2: Das Gehirn

Backend & APIs

Die unsichtbare Logik im Hintergrund. Hier werden Daten berechnet, geladen und sicher verwahrt.

  • Der Server: Ein Computer im Netz (wie dein VPS), der rund um die Uhr auf Anfragen wartet.
  • APIs (Die Kellner): Schnittstellen, die Daten (oft als JSON-Text) zwischen Server und Browser hin und her transportieren.
  • Dein Status: Dein Cockpit-Backend liefert To-Dos über eine API.
Säule 3: Die Zeitmaschine

Git & Versionskontrolle

Das wichtigste Werkzeug für Entwickler, um Code-Chaos zu verhindern und im Team zu arbeiten.

  • Repository: Der "Projektordner" auf GitHub, in dem alle Versionen deiner App liegen.
  • Commits: Die Speicherpunkte (Savegames). Wenn etwas schiefgeht, springst du einfach zurück.
  • Dein Status: Du hast heute deinen Code vor dem "Bus-Faktor" gerettet, indem er auf GitHub gesichert wurde!
